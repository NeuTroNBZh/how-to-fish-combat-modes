# Changelog

## 2.0.0

- Renamed the mod to **Combat Modes** (`HowToFish.CombatModes`, config file `htf.combatmodes.cfg`).
- English and French texts, following the game language.
- Native interface for the menu, lobby, HUD, scoreboard and end screen, with a basic fallback.
- Tab shows a scoreboard instead of the journal during matches.
- Saving, server settings, game respawn and corpse revive are disabled during matches.

## 1.3.0

- New modes: **Free-for-all** and **Gun Game** for 2 to 8 players, with lobbies, respawns, kill tracking and a scoreboard.
- Gun Game ladder starts with the sniper rifle.

## 1.2.0

- Random attachments for every round, identical for all players.
- Knife-only rounds.

## 1.1.0

- A different island for every duel round.
- Quick match merges players who search at the same time.

## 1.0.0

- **1v1 Duel** in rounds with random weapon kits, invite and quick match lobbies.
