# Combat Modes

Competitive multiplayer modes for **How to Fish**: fight your friends on the game's islands with a native-looking menu, lobby, HUD and scoreboard.

| Mode | Players | Goal |
|---|---|---|
| **1v1 Duel** | 2 | First to win 5 rounds. Random weapon kit, attachments and island every round. |
| **Free-for-all** | 2–8 | First to 20 kills, or the best score after 10 minutes. Shared kit that changes every 2 minutes. |
| **Gun Game** | 2–8 | Each kill gives the next weapon: sniper → assault rifle → SMG → shotgun → bow → pistol → knife. First knife kill on the last level wins; getting knifed sends you back one level. |

## Features

- Native interface built from the game's own UI, with a hold-Tab scoreboard.
- Fair loadouts: everyone gets the same weapons and the same random attachments.
- Invite friends through the Steam overlay or use quick match.
- No saving, server settings, respawn or revive exploits during matches.
- English and French, following the game language.

## How to play

1. Main menu → **Combat Modes** → choose a mode.
2. **Invite friends** or **Quick match**.
3. In Free-for-all and Gun Game, the host clicks **Start** (2+ players).

**Every player needs the mod, in the same version.**

## Configuration

`BepInEx/config/htf.combatmodes.cfg` (the host's settings apply): rounds, timers, weapon kits, gun game ladder, respawn delay, island rotation and more. See the [full table on GitHub](https://github.com/NeuTroNBZh/how-to-fish-combat-modes#configuration).
