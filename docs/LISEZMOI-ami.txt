MODS DE COMBAT pour How to Fish (Duel 1v1, Mêlée générale, Course à l'armement)
================================================================================

Installation (une seule fois)
1. Steam > clic droit sur How to Fish > Gérer > Parcourir les fichiers locaux.
2. Extraire TOUT le contenu de ce zip dans ce dossier (à côté de "How to Fish.exe").
   Accepter de remplacer les fichiers si Windows le demande.
3. Lancer le jeu : un bouton "Mods de combat" apparaît dans le menu principal.

Jouer
- Menu principal > Mods de combat > choisir le mode.
- Inviter des amis : l'hôte invite via l'overlay Steam, les autres acceptent.
- Partie rapide : tout le monde clique Partie rapide dans le même mode ; le premier
  crée le salon, les suivants le rejoignent automatiquement.
- Mêlée générale et Course à l'armement : 2 à 8 joueurs, l'hôte clique Lancer.
  Tab affiche le tableau des scores.

Modes
- Duel 1v1 : premier à 5 manches, 90 s par manche, kit et île aléatoires.
- Mêlée générale : premier à 20 kills (ou meilleur score après 10 min), kit
  commun changé toutes les 2 min, réapparition après 3 s.
- Course à l'armement : chaque kill donne l'arme suivante (sniper, fusil d'assaut, SMG,
  fusil à pompe, arc, pistolet, couteau). Tué au couteau = un niveau
  en moins. Le premier kill au couteau au dernier niveau gagne.

Tous les joueurs doivent avoir la même version du mod et du jeu.


Désinstaller : supprimer winhttp.dll (désactive tous les mods) ou le dossier
BepInEx\plugins\HowToFish.CombatModes (retire seulement les modes de combat).
